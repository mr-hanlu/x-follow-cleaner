使用流程

  1. 导出关注列表在 X 页面打开油猴面板，按折叠说明复制 Following cURL 并导出。
  2. 检查最近可见推文不携带 X 登录 Cookie，请求公开主页并获取最近可见推文时间。
  3. 筛选并标记按距最近可见推文天数、粉丝数和数据状态筛选，标记保留或待取消。
  4. 发送待取消队列把当前选择同步回油猴；已成功处理的账号不会重复加入。
  5. 返回 X 分批执行设置本批数量和间隔，确认后执行。

数据默认保存在当前浏览器。建议定期使用“保存进度 CSV”备份。
